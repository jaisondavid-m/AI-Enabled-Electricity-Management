## Overview

**EcoWatts AI** is a full-stack web application that helps Indian households monitor their electricity consumption, calculate CO₂ emissions, and receive personalised energy-saving recommendations powered by DeepSeek AI. The app calculates real-time energy costs using India's average grid values and presents the data through an intuitive dashboard with charts, gauges, and KPI cards.

---

## Features

### 🔐 User Authentication
- **Register & Login** — secure account creation and sign-in with form validation.
- **bcrypt Password Hashing** — passwords are never stored in plain text (10 salt rounds).
- **Persistent Sessions** — user session is stored in `localStorage` so it survives page refreshes.
- **Duplicate Email Protection** — the API returns a `409 Conflict` if the email is already registered.

---

### 📱 Device Management
- **Add Devices** — enter any home appliance with its name, category, power (watts), daily usage (hours), and days per week.
- **Device Presets** — one-click quick-fill from 8 common appliances:
  - LED Bulb, Ceiling Fan, Air Conditioner, Refrigerator
  - Washing Machine, Television, Laptop, Water Heater
- **Device Categories** — organise appliances into 7 categories:
  - 💡 Lighting, ❄️ Cooling / Heating, 🍳 Kitchen Appliances
  - 🫧 Laundry, 📺 Entertainment, 💻 Office / Work, 🔌 Other
- **Optional Usage Time** — record *when* a device is typically used (e.g. "10 PM – 6 AM").
- **Search & Filter** — instantly filter the device list by name or category.
- **Delete Individual Devices** — remove a single appliance with one click.
- **Clear All Devices** — bulk-delete all registered appliances.
- **Summary Strip** — live totals of device count, daily kWh, and monthly cost displayed at the top of the device list.

---

### ⚡ Automatic Energy Calculations
All calculations happen automatically when a device is added, using Indian grid constants:

| Metric | Formula | Constant |
|---|---|---|
| Daily Energy (kWh) | `(watts / 1000) × hours × (days / 7)` | — |
| Daily CO₂ (kg) | `kWhPerDay × 0.82` | India CEA 2023: **0.82 kg CO₂/kWh** |
| Monthly Cost (₹) | `kWhPerDay × 30 × 7` | Average India tariff: **₹7 / unit** |

---

### 📊 Interactive Dashboard
The dashboard gives a full picture of household energy health:

- **KPI Cards** — four at-a-glance metrics:
  - Total daily energy consumption (kWh/day)
  - Estimated monthly electricity bill (₹/month)
  - Total daily CO₂ emissions (kg CO₂/day)
  - Top energy-consuming device
- **Donut / Ring Chart** — colour-coded canvas visualisation showing each device's share of total daily energy.
- **Bar Chart** — horizontal bars ranked by kWh/day for easy comparison across all devices.
- **CO₂ Gauge** — SVG circular gauge that rates annual CO₂ impact as **Low / Moderate / High** with a colour-coded indicator.

---

### 🤖 AI Energy Analysis (DeepSeek)
Powered by **DeepSeek** (`deepseek/deepseek-chat`) via the OpenRouter API:

- **Personalised Analysis** — the AI receives your exact device list, wattages, usage patterns, and cost summary.
- **Five-Section Report** generated by the AI:
  1. **Overall Assessment** — energy usage rating (Low / Medium / High), biggest consumer, annual CO₂ estimate.
  2. **Top 5 Recommendations** — device-specific, actionable tips (e.g. "Replace your Water Heater timer to cut standby losses by 15%").
  3. **Smart Scheduling** — exact time-of-day guidance for each high-consumption device; highlights off-peak hours (10 PM – 6 AM).
  4. **Estimated Monthly Savings** — conservative and optimistic estimates of CO₂ saved (kg/month) and money saved (₹/month) if recommendations are followed.
  5. **⚡ #1 Quick Win** — one single action the user can take *today*.
- **Indian Context** — uses ₹ currency, 0.82 kg/kWh Indian grid CO₂ factor, and Indian appliance naming conventions.
- **Formatted Output** — markdown from the AI is parsed into styled HTML with section headings, bullet lists, and highlighted saving/quick-win callout boxes.

| Tip | Benefit |
|---|---|
| Night Shift Scheduling | Grid load 30–40% lower after 10 PM |
| AC Temperature Hack | Each degree above 24°C saves ~6% energy |
| Water Heater Timer | Eliminates 15% standby losses |
| Daylighting Strategy | Saves 2–3 kWh/day from natural light |
| Phantom Load Elimination | Removes 0.1–0.2 kWh/day from standby devices |

### 📄 PDF Report Generation
- **Branded PDF** — generated client-side with **jsPDF** in A4 format.
- **Report Contents:**
  - EcoWatts AI branding header with the user's name and date
  - KPI summary section (total kWh, CO₂, monthly cost)
  - Full device table sorted by energy consumption
  - CO₂ impact section with annual projection
  - Inline AI recommendations (if an analysis has been run)
  - UN SDG 13 Climate Action footer
- **One-click download** straight from the Dashboard.

---

### 📧 Email Report
- **Send Report by Email** — delivers the same data as the PDF but as a richly styled **HTML email** via Nodemailer (Gmail SMTP).
- **Email Contents:**
  - Gradient branded header
  - Device table sorted by kWh/day with zebra-stripe rows
  - Summary KPIs (total energy, CO₂, cost)
  - AI recommendations section (if available)
  - Sent to the logged-in user's registered email address

---

### 🔔 Toast Notifications
- Non-blocking toast pop-ups confirm every user action (device added, deleted, report sent, errors, etc.).
- Auto-dismiss after 3.5 seconds.
- Two variants: **success** (green) and **error** (red).

## Getting Started

### Prerequisites

- **Node.js** v18 or higher
- **MySQL** 8.0 or higher
- A **Gmail account** with an [App Password](https://myaccount.google.com/apppasswords) enabled
- An **OpenRouter API key** (free tier available at [openrouter.ai](https://openrouter.ai))

---

### Environment Variables

#### Server (`server/.env`)

```env
PORT=5000

DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_mysql_password
DB_NAME=ecowatts

GMAIL_APP_PASSWORD=your_gmail_app_password
```

#### Client (`client/.env`)

```env
VITE_API_URL=http://localhost:5000
VITE_OPENROUTER_API_KEY=your_openrouter_api_key
```

---

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/AI-Enabled-Electricity-Management.git
   cd AI-Enabled-Electricity-Management
   ```

2. **Install server dependencies**
   ```bash
   cd server
   npm install
   ```

3. **Install client dependencies**
   ```bash
   cd ../client
   npm install
   ```

4. **Create and configure `.env` files** in both `server/` and `client/` as shown above.

5. **Create the MySQL database** (tables are created automatically on first run):
   ```sql
   CREATE DATABASE ecowatts;
   ```

---

### Running the App

**Start the backend server:**
```bash
cd server
npm start
```
The API will be available at `http://localhost:5000`.

**Start the frontend dev server (new terminal):**
```bash
cd client
npm run dev
```
Open `http://localhost:5173` in your browser.

## Usage Guide

1. **Create an account** on the Auth page, then log in.
2. **Go to Device Management** and add your home appliances. Use presets for commonly used devices.
3. **View the Dashboard** to see your total energy consumption, monthly cost, and CO₂ footprint visualised across KPI cards, a ring chart, bar chart, and CO₂ gauge.
4. **Run AI Analysis** from the AI Energy Analysis page to receive personalised, device-specific recommendations from DeepSeek AI.
5. **Generate a PDF Report** from the Dashboard to download a printable monthly report.
6. **Email the Report** directly to your registered email with one click.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/health` | Server health check |
| `POST` | `/api/auth/register` | Register a new user |
| `POST` | `/api/auth/login` | Login and retrieve user info |
| `GET` | `/api/devices?userId=<id>` | Fetch all devices for a user |

## Database Schema

```sql
-- Users table
CREATE TABLE users (
  id         BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  name       VARCHAR(120)    NOT NULL,
  email      VARCHAR(191)    NOT NULL,
  password   VARCHAR(255)    NOT NULL,   -- bcrypt hash
  created_at TIMESTAMP       DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uniq_users_email (email)
);

-- Devices table
CREATE TABLE devices (
  id           BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  user_id      BIGINT UNSIGNED NULL,
  name         VARCHAR(120)    NOT NULL,
  category     VARCHAR(60)     NOT NULL,
  watts        DECIMAL(10,2)   NOT NULL,
  hours        DECIMAL(10,2)   NOT NULL,
  days         INT             NOT NULL DEFAULT 7,
  time         VARCHAR(200)    DEFAULT NULL,
  kwhPerDay    DECIMAL(12,3)   NOT NULL,
  co2PerDay    DECIMAL(12,3)   NOT NULL,
  costPerMonth DECIMAL(12,1)   NOT NULL,
  created_at   DATETIME(6)     DEFAULT CURRENT_TIMESTAMP(6),
  PRIMARY KEY (id)
);
```

> Tables are created automatically when the server starts — no manual migration needed.
